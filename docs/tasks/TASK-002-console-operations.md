# TASK-002 · 本机 Console 的登录、日志与启动配置

基线 `6a636ae`。沿用独立 Host、本机管理和每个数据目录独立授权。Console 面向部署者，Client 继续处理身份与聊天。

- 通过 Console 查看 Nexus 专用 Codex 的登录状态、发起官方授权、取消和退出或更换账号。刷新页面能接续尚未结束的登录操作，使用中的任务受到保护。令牌和凭据由官方 Runtime 管理。
- 提供近期 Host 日志，带时间、级别和事件，可刷新和筛选。采用有限保留和可公开的诊断字段，避免记录聊天、认证材料和审批内容。说明日志级别、单轮超时、默认 Runtime 各自的用途和生效时机。
- 可以选择本机监听地址、端口、数据目录；需要目录的位置提供本机文件夹选择与手动输入。区分已生效设置与下次启动设置，支持保存后返回、立即重启及单独重启。保留双击和命令行入口，重启前确认任务数和实例，处理目标不可用和重开 Console 地址。
- 确认数据目录语义后记录，旧数据须可找回。验收使用独立端口和临时数据，覆盖已登录和未登录、重启时的任务和历史、端口冲突、恶意来源拒绝及误切目录。交付真实可核查证据，涉及真实账号的人工步骤与合成验收分开记录。
