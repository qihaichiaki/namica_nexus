# ADR 003 · Nexus 的 Codex 线程存储

**状态**　已实施，2026-11-25。

**背景**　原版共用当前用户的 Codex 存储，Nexus 对话可能进入日常 Codex 的最近列表。用户希望隐藏这些聊天，同时在重新启动 Nexus 后保留原生上下文。

**备选方案**　临时线程省去持久化，但当前每个 Turn 单独启动 App Server，需要按原生线程 ID 恢复。事后归档会先写入共享历史，执行中断还会留下未归档条目。仅调整 SQLite 目录无法同时隔离原生线程文件和配置。

**决定**　每个 Nexus 数据目录使用自己的 Codex home。Host 与登录辅助命令复用相同的目录与代理配置。Adapter 在启动握手时核对 Codex 返回的存储位置，检查失败即终止调用。无需读取或复制个人 Codex 的认证文件。

**影响**　专用线程可跨进程恢复，原生日常列表不会收录新线程。每个新数据目录需要首次官方登录；同一 Windows 用户可以直接读取自己有权限访问的数据目录，模型服务仍接收对话内容。升级保留旧库和普通 Codex 的既有线程，旧 Nexus 消息可查看，新对话在专用目录内开始。验证方式见 [Runtime 实测](../runtime-verification.md)。
