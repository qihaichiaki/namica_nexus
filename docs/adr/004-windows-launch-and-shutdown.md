# ADR 004 · Windows 启动入口与 Web 管理界面

**状态**　2026-11-25，负责人确认修订。交付见 [TASK-001](../tasks/TASK-001-windows-launch-and-shutdown.md)。

**背景**　浏览器无法冷启动尚未监听的 Host。管理部署环境与使用 AI 身份有不同的受众，未来其他设备只需访问业务能力。

**决定**　双击 Namica Nexus 启动或复用本机同一 Host，待就绪后自动在默认浏览器打开 Nexus Console。Host 独立于窗口和浏览器运行。Console 负责本机配置与显式停止服务，提供打开 Nexus Client 的入口。两个 Web 入口共享一个 Host、同一份业务数据及后台任务。

**取舍**　将冷启动交给轻量 Windows 入口，将配置和关停交给 React 管理页，省去第二套原生管理界面。重复双击复用实例，浏览器可能新建标签页。本次保留回环监听和现有本机信任边界。关网页仅断开该页面。显式停止 Host 会中断正在执行的任务并保留已落盘历史。

**决定演进**　先前的原生管理窗口、托盘必需和手动打开网页的方案由此次决策取代。托盘可在以后作为便利功能评估。

**启动配置与迁移**　负责人在 [TASK-002](../tasks/TASK-002-console-operations.md) 中选择迁移现有数据。启动器和 Host 共享独立于数据目录的部署配置，分别记录当前设置和下次启动设置。管理端继续限本机，可选择 IPv4 或 IPv6 回环地址和端口。用户确认重启后，Host 结束活动任务与 Runtime、关闭数据库，再向空目标迁移。新实例使用新位置，旧目录保留作备份。普通关页、保存后返回、明确重启是三种不同操作。
